开通功能管理

配置 App 可开通功能与付费套餐 · 须先在 运维 Hub 登录

怎么用：先建「功能定义」（App 列表里的一项能力），再为该功能建「售卖套餐 / SKU」（用户付钱时选的商品）。 浏览器只带 Admin JWT，不发送 X-Admin-Password。 价格单位一律为分（6 元请填 600）。预测可看条数功能编号固定为 prediction_unlock（种子已有，一般只需加套餐）。

一、功能定义（App 目录项）

定义「有哪些功能、允许用什么方式开通」。改编号会影响已上线客户端，勿随意改已有 ID。

系统稳定 ID，英文/下划线。例：prediction_unlock
用户在 App 里看到的标题
逗号分隔：payment=付费，invite_code=邀请码，ad=广告
上架后出现在 App 功能列表
数字越小越靠前
功能编号 显示名称 开通方式 上架

二、售卖套餐（SKU / 商品）

每个套餐对应一次可购买的「商品编码」。App 从功能列表的 products 里展示价格，建单时提交本页的商品编码。 开通类型：增加预测条数请选「增加可看数量」；开通某功能权益选「功能权益」。

全局唯一，建单用。例：pred_count_5
必须填上面已有的功能编号
预测条数用「增加可看数量」
增加几条 / 权益一般填 1
单位「分」：6 元 = 600
0 表示不展示划线价
0 = 永久；权益类才常用
IAP 用；没有可留空
商品编码 所属功能 开通类型 × 数量 现价 上架
