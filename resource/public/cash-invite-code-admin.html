邀请码管理

推广/渠道邀请码 · 兑换追踪 · 运维 Hub

用途：给销售/渠道发邀请码，用户在 App 输入码开通指定功能（可逐个功能兑换，不会一次开完全部）。 规则摘要：一人只能绑定「一家」持有人的码；不可用自己的码；仅兑换成功开通某一功能后才绑定该持有人。 持有人账号 ID是系统里的 wx 数字主键（不是手机号/微信号文案），一期每个持有人只能有一条邀请码。

创建邀请码

wx 表主键数字；销售/渠道绑这个人
发给用户输入；留空则自动生成
逗号分隔；须与「开通功能管理」里一致。例：prediction_unlock。留空=所有支持邀请码的功能
按成功开通次数计；0 = 不限制
0 = 永久（预测条数类通常填 0）
