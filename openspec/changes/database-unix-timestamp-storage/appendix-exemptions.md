# 附录：豁免或单独约定的字段

## user.birthday（及对外「生日」接口）

- **现状**：`entity.User.Birthday` 为 `string`，历史上可能存时间戳串或业务约定日期串。
- **豁免理由**：生日多为「日历日」语义，不等价于 UTC 瞬时；若强改为 Unix 秒需统一「当日 00:00 UTC」等业务规则，须产品确认。
- **建议**：在「时刻」迁移批次中**单独评审**：可选 `DATE`、或保留字符串但明确 schema；**不**与 `start_time` 等事件时刻混用同一套回填脚本。

## 非落库的 time.Format

- 代码中用于 **LLM 上下文、日志、缓存 key** 等的 `time.Format("2006-01-02 ...")` **不属于**本变更「落库权威形态」；迁移时勿误改为写入 DB。
